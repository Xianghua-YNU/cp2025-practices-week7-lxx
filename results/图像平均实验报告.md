# 图像平均滤波实验报告

## 实验目的
1. 理解图像平均滤波的基本原理, 理解卷积的意义
2. 掌握使用不同尺寸滤波器对图像进行平滑处理的方法
3. 分析不同尺寸滤波器对图像处理效果的影响

### 实验任务 

(a) 创建3×3平均滤波器
```python
small_filter = np.ones((3,3))/9
 ```
 (b) 应用小滤波器处理图像
```python
small_result = sim.convolve(img, small_filter)
 ```
 (c) 创建并应用15×15平均滤波器
```python
large_filter = np.ones((15,15))/(15*15)
large_result = sim.convolve(img, large_filter)
 ```

## 实验结果分析
1. 总结不同尺寸滤波器的特点
2. 分析滤波器尺寸对处理效果的影响
3. 探讨实际应滤波器尺寸影响：

小滤波器(3×3)：保留更多高频细节，适合去除椒盐噪声

大滤波器(15×15)：产生更强平滑效果，适合去除高斯噪声

卷积运算特性：

线性操作：满足叠加性和齐次性

空间不变性：对图像不同位置效果一致

低通滤波：抑制高频成分，保留低频成分

实际应用选择：

需要平衡噪声消除和细节保留

3×3适合精细图像处理

15×15适合预处理或需要强平滑的场景

可通过实验选择最佳尺寸用中的选择策略

卷积核值取1/9(或1/225)保证了：

亮度保持性（核元素和为1）

平滑效果（均匀权重）

避免引入偏移（无偏估计）
